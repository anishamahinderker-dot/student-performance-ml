# Student Performance Prediction (ML Project)

##  Overview
This project predicts student math scores based on reading and writing scores using Machine Learning.

##  Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

##  Features
- Data preprocessing using Pandas
- Linear Regression model for prediction
- Model evaluation using R² score (~0.99)
- Visualization of actual vs predicted values

##  How to Run
1. Install dependencies:
   pip install pandas numpy scikit-learn matplotlib

2. Run the program:
   python main.py

##  Output
- Displays prediction accuracy
- Shows graph of actual vs predicted scores

##  Learning Outcome
- Understanding of supervised learning
- Hands-on experience with real dataset
- Model training and evaluation
